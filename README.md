# 🤖 IA + Automação — Jornada de Estudos 2026

> **De:** "sei usar ferramentas de TI"
> **Para:** "sei construir automações com IA"

Repositório onde documento um plano de estudos de ~4 meses (ago–dez/2026), evoluindo de
Suporte de TI para automação de processos com Python, APIs, n8n, Inteligência Artificial,
bancos de dados e Docker — aplicado em cima da infraestrutura que já conheço no dia a dia
profissional (Active Directory, VMware, Wazuh, backups, firewalls).

A ideia não é apenas "aprender a usar IA". É aprender a **identificar processos repetitivos,
automatizá-los de ponta a ponta, e usar IA somente quando ela realmente agrega valor** dentro
de um processo — não como um chatbot isolado.

---

## 🎯 Objetivo final

Ao final de 2026, ser capaz de:

> Identificar um processo → entender os dados envolvidos → criar uma automação → integrar
> APIs → utilizar inteligência artificial quando necessário → armazenar informações →
> monitorar o processo → entregar uma solução funcionando.

**A trilha:**

```
Python → APIs → n8n → IA → Banco de Dados → RAG → Agentes de IA → Wazuh → Docker → Projeto Final
```
